# Mobile UX pass — 2026-09-21

Walked on emulator `GravityRoom_API35` (Expo Go, 1080×2400) against the local API, signed in as `dev@localhost.dev`. Surfaces: login, Train/tracker, My plans, Explore, Exercises, More.

## Decisions

| Surface         | Finding                                                                                                                                                                                                                                                              | Decision | Why                                                                                                                                                                                                                   |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Login           | "Continue with Google" is the primary button and stays disabled, with no explanation, when no Google client id is configured.                                                                                                                                        | Fix      | The first action on the screen does nothing. Email is the path that works here, so it becomes the primary control and the dead Google button is not shown.                                                            |
| Login           | Dev Login is visible in development builds.                                                                                                                                                                                                                          | Defer    | It is the local sign-in path and is compiled out of production builds.                                                                                                                                                |
| Train / tracker | Opening the app lands on the most recently updated plan. "Custom mesocycle" (`hypertrophy-custom`, catalog 404) and "Full body 3 days" (`gr-full-body-3`, catalog 500 hydration) both stop on "Tracker unavailable" with no reason. GZCLP on the same account opens. | Fix      | Train now skips a plan whose template is missing or unreadable and opens the next one. Opening one of those plans on purpose explains why it cannot be trained and how to leave, instead of a bare unavailable title. |
| Train / tracker | The Fail action on the active set sits against the tab bar, and the first Explore row is clipped by the same bar.                                                                                                                                                    | Fix      | Workout scroll content clears the tab bar and the active set is brought fully above it. Explore and My plans lists get the same bottom clearance so a row can scroll clear of the bar.                                |
| Train / tracker | Header shows English "WEEK 1 DAY 2" beside the template's Spanish day name ("Día 2"), and exercise names stay in the catalog language.                                                                                                                               | Defer    | The strings come from stored program content, not the UI catalog. Translating the seed library is a content project, not this pass.                                                                                   |
| Train / tracker | GZCLP on this account still logs at 2.5 kg.                                                                                                                                                                                                                          | Defer    | New starts already ask for starting weights. Rewriting loads on an in-progress plan is a training-rule change.                                                                                                        |
| Train / tracker | Duplicate-start confirm is a light system alert.                                                                                                                                                                                                                     | Defer    | The copy is clear and the confirm already blocks a second plan. Restyling the platform dialog is cosmetic.                                                                                                            |
| Train / tracker | Red Expo Go toast: `expo-notifications` push was removed from Expo Go.                                                                                                                                                                                               | Defer    | Local scheduling still runs. Replacing Expo Go with a development build is out of scope.                                                                                                                              |
| My plans        | Recent plan, other plans, delete, and Explore entry are understandable. The recent plan can be one the tracker cannot open.                                                                                                                                          | Defer    | The Train fix covers landing on it. Delete and the list itself do not need a new control.                                                                                                                             |
| Explore         | Catalog browse, level chips, detail sheet, and duplicate-start confirm work. GZCLP copy says 3 days/week while the description mentions a 4-day rotation.                                                                                                            | Defer    | The contradiction is catalog flavor text, not the screen structure.                                                                                                                                                   |
| Exercises       | Placeholder: "Your exercise library will appear here."                                                                                                                                                                                                               | Defer    | Building the library was not part of this pass.                                                                                                                                                                       |
| More            | Profile shows name, email, session note, and sign out. No other account settings.                                                                                                                                                                                    | Defer    | Extra settings were not part of this pass. The screen does the one job it has.                                                                                                                                        |
