Use case: ui-mockup. Create an imaginative but buildable high fidelity mobile UI concept for Gravity Room, a serious strength training app. Portrait single edge-to-edge app screen, no device frame. Screen is program discovery/Templates. Evolve the existing warm near-black and gold identity into a premium editorial sports product. User should be able to scan and compare programs quickly, not read enormous paragraphs and repeated yellow Start buttons. Top small brand GRAVITY ROOM, large heading "Find your next program", concise subheading. Compact functional search field. Filter pills All, Beginner, Intermediate. One featured GZCLP card with subtle abstract stacked weight plates graphic in muted charcoal and gold (code-buildable geometry), label STRENGTH FOUNDATIONS, title GZCLP, small 3 days/week and Beginner metadata, one restrained primary button View program. Below, a section All programs with compact list cards: 5/3/1 for Beginners, Boring But Big, each with a small abstract monogram tile, clear name, concise metadata and a trailing chevron; no repeated big yellow buttons. Bottom five labeled icons Workout, Mesos, Templates, Exercises, More, Templates selected. Typography refined modern sans serif, excellent readable hierarchy, near-black canvas, subtle warm grey cards, creamy white text, scarce amber yellow. Confident spacing, fine details, realistic native controls, no gradients/glows, no fake ratings or invented testimonials. This is an exploratory design image to subsequently implement as real React Native components.
